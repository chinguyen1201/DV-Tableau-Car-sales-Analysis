# DV-Tableau-Car-sales-Analysis
Developed an interactive data visualization project using Tableau to analyze car sales data. The project covered data profiling, abstraction, task design, and the creation of animated dashboards to reveal sales patterns and insights.
- Tableau link: https://public.tableau.com/shared/9F9PSDKBY?:display_count=n&:origin=viz_share_link
